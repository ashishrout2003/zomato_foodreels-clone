# 🍽️ Zomato Reels Clone

A full-stack **Zomato Food Reels Clone** web application where users can watch food reels, like, comment, and explore trending food content.  
Built with **MERN Stack** (MongoDB, Express.js, React.js, Node.js).

---

## 🚀 Features

### 👤 User Features
- ✅ User authentication (Register / Login)
- ✅ Watch food reels
- ✅ Like & Unlike reels
- ✅ Comment on reels
- ✅ View trending reels
- ✅ Responsive UI (Mobile + Desktop)

### 🛠️ Admin/Backend Features
- ✅ Create / Upload reels
- ✅ Manage reels data (CRUD)
- ✅ API endpoints for reels, users, likes & comments
- ✅ Secure routes using JWT authentication
